What is Visual DNA?

Visual DNA captures the visual grammar behind an interface: its workspace structure, density, typography, geometry, colour, controls, panels, menus, toolbars, tabs and interaction states.

Design languages, not app features

Describe how an interface looks and behaves visually, independently of the application being built.

Reference-led

Build a clear, reusable description from a named product, version or visual reference.

AI-ready skills

Organise each design language as a folder containing a focused SKILL.md that an AI agent can read and apply.

Honest implementation guidance

Keep portable design principles separate from framework-specific techniques. A port is only validated when tested.

How it works

A simple, repeatable process designed to keep contributions focused and reusable.

Choose a reference

Identify the software, product version and visual scope.

Capture its visual DNA

Document the visual rules and distinctive interface patterns.

Create the skill

Write a focused SKILL.md in its own folder.

Apply it elsewhere

Use the skill as visual direction for a different application.
